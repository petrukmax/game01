## 📝 Руководство по использованию

### Добавление нового проекта
1. Создайте новую директорию в соответствующем разделе
2. Добавьте README с описанием проекта
3. Закоммитьте изменения
4. Создайте ветку для разработки

### Тестирование
```bash
# Пример для Python проекта
python -m pytest tests/

# Пример для Node.js проекта
npm test
```
